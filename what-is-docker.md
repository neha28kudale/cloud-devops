# 🐳 What is Docker?

##Introduction
Docker is a tool that helps developers package applications into containers.

##Why Docker?
Applications may not run the same on different systems due to dependency issues.

Docker solves this by creating a consistent environment.

##What is a Container?
A container is a lightweight package that includes:
- Code
- Libraries
- Dependencies

##How Docker Works
- Docker Image → blueprint
- Docker Container → running app

##Basic Workflow
1. Write code
2. Build image
3. Run container

##Example
docker build -t myapp .
docker run myapp


##Advantages
- Fast
- Portable
- Consistent

##Conclusion
Docker ensures applications run the same everywhere.
